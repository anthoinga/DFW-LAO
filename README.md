# DFW Lao Heritage

Website and content studio for [DFW Lao Heritage](https://www.dallasfwlaoheritage.com), a 501(c)(3)
nonprofit preserving Lao arts and culture in Dallas–Fort Worth.

| App                          | What it is                                                                         | Runs on                         |
| ---------------------------- | ---------------------------------------------------------------------------------- | ------------------------------- |
| [`apps/web`](apps/web)       | Public site (English + Lao), digital cards at `links.`, agent/API endpoints, forms | SvelteKit on Cloudflare Workers |
| [`apps/studio`](apps/studio) | Content dashboard for editors                                                      | Sanity Studio                   |

Project background, decisions and architecture live in [`context/`](context/README.md).

## Requirements

- Node 22 (`.nvmrc`) and pnpm 10 (`corepack enable`)

## Setup

```sh
pnpm install
cp apps/web/.env.example apps/web/.env            # vite dev
cp apps/web/.env.example apps/web/.dev.vars       # wrangler preview
cp apps/studio/.env.example apps/studio/.env
pnpm --filter web db:migrate                      # local D1 tables
```

Everything runs without credentials: the site falls back to built-in organization details until a
Sanity project ID is set, and optional features (chat, translation, email, wallet passes) switch on
when their keys are present.

## Commands

| Command                      | Does                                                                   |
| ---------------------------- | ---------------------------------------------------------------------- |
| `pnpm dev`                   | Site at http://localhost:5173 (card host: http://links.localhost:5173) |
| `pnpm dev:studio`            | Studio at http://localhost:3333                                        |
| `pnpm lint` / `pnpm format`  | Prettier + ESLint                                                      |
| `pnpm check`                 | Type checks (svelte-check, tsc)                                        |
| `pnpm test`                  | Unit tests (Vitest)                                                    |
| `pnpm --filter web test:e2e` | Smoke tests against a production build (Playwright)                    |
| `pnpm build`                 | Build site and studio                                                  |
| `pnpm typegen`               | Generate TypeScript types from the Sanity schema                       |
| `pnpm i18n:ui`               | Translate new interface strings into Lao (`messages/lo.json`)          |
| `pnpm i18n:backfill`         | Translate CMS content into Lao (normally automatic on publish)         |

## Conventions

- **Imports:** `#lib/...` with file extensions (`#lib/config.ts`, `#lib/seo/Seo.svelte`).
- **Server-only code** lives in `src/lib/server/`. Environment variables are declared in `apps/web/src/env.ts`.
- **Content** is authored in English only. Lao is generated by the translation pipeline and can be
  reviewed in the Studio.
- **Sensitive submissions** (community help requests, camp registrations) are stored in Cloudflare D1
  and viewed at `/admin/submissions` behind Cloudflare Access — never in the CMS.
- **Generated files** (Paraglide output, Sanity types, Worker types, builds) are not committed.
- **Commits:** conventional style (`feat:`, `fix:`, `chore:` …), one concern per commit.

## Deploy

- **Site:** `pnpm --filter web build && pnpm --filter web exec wrangler deploy`. Secrets via
  `wrangler secret put <NAME>`; see `apps/web/.env.example` for the full list.
- **Studio:** `pnpm --filter studio deploy`.
- **Design previews (Vercel):** import the repo in Vercel with Root Directory `apps/web` and the
  SvelteKit preset. Vercel sets `VERCEL=1`, which switches the build to the Vercel adapter. Previews
  are `noindex`, cards live under `/links`, and features that need Cloudflare (form storage, chat
  rate limits) report themselves as unavailable.
- **CMS webhook:** on publish of translatable types, POST `{_id, _type}` to `/api/i18n/translate`
  with the shared secret.
